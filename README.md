

## Python Lab Exercises 1

These exercises are designed to help you practice and reinforce your understanding of Python programming concepts. Each exercise builds on the previous ones, gradually increasing in complexity.
You do not have to complete all the exercises in one go. Take your time, and feel free to come back to them later.

Your first challenge is to read this file. It's known as a Markdown file. Markdown is a lightweight markup language that allows you to write formatted text using a simple syntax, but it needs a reader to understand it. The most common reader is a web browser, but you can also use a Markdown editor. I recommend Visual Studio Code (VS Code) for this. If you are reading this in VS Code, you can press `Ctrl+Shift+V` to preview it formatted.

### **Exercise 1: Greeting with Type Awareness**

**Objective:** Practice using `str`, `int`, and `float` types, and basic `input()`/`print()` functionality.

### **Exercise 2: Multiple Types & Input Formatting**

**Objective:** Reinforce variable usage and type clarity with formatted output.

### **Exercise 3: Type Conversion and Arithmetic**

**Objective:** Combine arithmetic operations while managing correct data types.

### **Exercise 4 (Challenge): Simple Conditional Calculator**

**Objective:** Use type conversion, string input, conditional logic (`if/elif`), and error-checking for division.

### **Exercise 5 (Challenge): Looping Calculator with Type and Control Awareness**

**Objective:** Design a loop, manage types, input/output, logic, and boolean control flow. From scratch 

**Instructions (you write this from scratch):**

* Ask for two numbers (as floats or ints).
* Ask which operation to perform (`+`, `-`, `*`, `/`).
* Compute and display the result, handling division by zero.
* Ask if the user wants another calculation (`yes`/`no`).
* Continue looping until user says "no".
* Use a boolean variable to control the loop.
